# 📝 Quiz Application

A simple and interactive **Quiz Application** built using HTML, CSS, and JavaScript. This project allows users to test their knowledge through multiple-choice questions and view their scores.

## 🌐 Live Demo

🚀 [Click here to try the Quiz Application](https://gagankdev.github.io/Quize-application/)

## ✨ Features

- Interactive multiple-choice quiz.
- User-friendly and clean interface.
- Instant answer selection.
- Score calculation based on correct answers.
- Displays quiz results at the end.
- Responsive design for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Quiz logic, answer validation, and score calculation.
